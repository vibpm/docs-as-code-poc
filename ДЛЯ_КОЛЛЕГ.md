# Docs-as-Code — демо для коллег

Короткий прогон: как устроен портал нормативного контента и как правка в CMS попадает на страницу.

## Доступ

| | |
|---|---|
| Портал | https://docs-as-code-poc.onrender.com |
| CMS | https://docs-as-code-poc.onrender.com/admin/ |
| Логин / пароль | `demo` / `demo2026` |

Если сайт «думает» 30–50 сек — это free-хостинг после простоя. Подождите и обновите страницу.

## Что смотреть на портале

1. Откройте главную → **Путеводитель по кадровым вопросам. Увольнение**  
   Прямая ссылка: https://docs-as-code-poc.onrender.com/hr.dismissal-guide/
2. Это **один** собранный документ (не набор отдельных «глав» как CMS-объектов).
3. Повторяющиеся нормы (расчёт, трудовая, сроки и т.п.) подключены как **общие блоки**: правка блока в одном месте меняет все вхождения на странице.

Рядом есть короткий документ «Общая процедура оформления увольнения» — тот же принцип сборки.

## Мини-сценарий: правка → портал

Цель: убедиться, что CMS → пересборка → портал работают end-to-end.

1. Откройте https://docs-as-code-poc.onrender.com/admin/ (тот же логин).
2. Слева: **Общие нормативные блоки**.
3. Выберите любой блок (например, про окончательный расчёт или трудовую книжку).
4. В поле **Текст** измените одну фразу так, чтобы её было легко заметить (добавьте пометку вроде `[демо]`).
5. **Save** / Publish.
6. Подождите **10–30 секунд** (на free-хосте иногда до минуты).
7. Обновите страницу путеводителя — новое формулирование должно появиться **везде**, где этот блок вставлен.

Откат: снова откройте тот же блок в CMS и уберите правку → Save.

## Что здесь принципиально

| Идея | Как видно в демо |
|---|---|
| Единый источник правды (SSOT) | Норма живёт в блоке; документ только ссылается на него |
| Документ = манифест | Состав разделов и ссылки на блоки, а не копия текста |
| Редактор без IDE | Decap CMS в браузере |
| Сборка портала | После Save сайт пересобирается автоматически |

Формулировки проблем и «ранний сигнал» по этому кейсу (для тех, кому интересен метод): папка `fpf/` в репозитории (CuePack + ProblemCard).

## Ограничения этого демо

- Это **PoC**, не боевой контур.
- Один общий пароль: любой с логином может править контент.
- Нет GitLab/GitHub OAuth и нет merge request / согласований — для продакшена они обязательны.
- Хостинг free: возможны «засыпание» и задержки сборки.
- Контент ЮрСпектр загружен для демонстрации архитектуры, не как публикация издания.
